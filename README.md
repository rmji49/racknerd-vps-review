## 一份美国VPS测评，至少要看哪几项

配置和价格只是入门项，真正拉开差距的是线路和稳定性。一份合格的评价至少该包含这几块：CPU 基准测试、带宽和流量额度、去程与回程路由、Ping 延迟、下载速度。

回程路由最值得花时间看。所谓回程，是数据从美国机房回到你这边的路径，它直接决定实际访问体验。路由表里出现的 AS9929、CN2 GIA、CMI 这类标注，分别对应联通精品网、电信 CN2、移动 CMI 的直连线路；走这些线路的机器，大陆访问质量明显好于普通绕路线路，价格也高出不少。

延迟可以给个参照系：华纳云公布的美国机房到中国的延迟数据在 142ms 左右，这是 CN2 GIA 直连线路的水准，普通线路因为绕路会更慢、波动更大。所以看到 ping 数字先别急着下结论，先看测的是什么线路。

稳定性是低价机最难保证的一项，也是短周期测评测不出来的部分——几天的观察发现不了三个月后的宕机，这部分只能靠商家的经营年头和口碑兜底。
